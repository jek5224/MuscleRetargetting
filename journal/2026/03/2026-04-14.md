# Research Journal — 2026-04-14

## Surface Contact Pipeline for Muscle Baking

### Problem
ARAP + vertex-only collision projection works for 90% of frames but hamstrings (semimembranosus, semitendinosus) penetrate femur by 12-14mm at deep knee flexion (frames 50-90). Vertex projection can't catch edge-through-bone cases.

### Approaches Tried

**1. ipctk surface contact (NormalCollisions)**
- Installed ipctk 1.5.0 on A6000 server (Python 3.10)
- Problem: 800K+ false-positive collision pairs because muscles naturally wrap near bones within dhat. Standard IPC penalizes ALL proximity, not just penetration.

**2. One-sided IPC (vertex inside + edge intersection)**
- Vertex-inside: closest_point + normal dot product (fast, correct)
- Edge-bone intersection: BVH ray casting via trimesh (correct)
- Problem: as splitting approach (ARAP → contact → repeat), ARAP pulls vertices back inside between outer loops

**3. Penalty-in-diagonal (ARAP modification)**
- Add collision_weight to L diagonal for candidate vertices
- Set targets: inside → surface, outside → current_pos
- Problem: outside candidates get anchored (extra stiffness), preventing convergence

**4. L-BFGS quasi-static (co-rotated FEM + one-sided barrier)**
- Proper energy minimization: elastic + contact in same objective
- Contact energy reduced 12,500x (1.2M → 98)
- Problem: no CCD, occasional L-BFGS spikes cause 141mm tunneling. Worse final result than ARAP.

**5. PolyFEM (Newton + IPC, proper solver)**
- Built from source on A6000 server
- Single muscle (10K verts, 37K tets): loads and builds collision mesh OK
- Full 25-muscle unified mesh (172K verts, 637K tets): segfaults during setup
- Next step: per-muscle polyfem solve

### Key Insight
The real problem is solver architecture, not detection. All approaches correctly detect penetrations but fail to resolve them because:
- Splitting (ARAP → fix → ARAP) creates oscillation
- Penalty without CCD allows tunneling
- L-BFGS without trust region creates catastrophic steps

PolyFEM's Newton + CCD is the correct answer but needs per-muscle batching to avoid the 637K tet segfault.

### Current Best Result
ARAP + vertex projection: 7s/frame, collision-free for frames 0-50 and 90-131. Hamstrings at frames 50-90 have 200-400 vertices at 12-14mm depth.
