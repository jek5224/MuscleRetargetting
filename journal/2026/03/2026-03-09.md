## Walk BVH Overfitting Test

Trained V1 DistillNet on walk.bvh (132 frames, 25 muscles) to verify the pipeline works before scaling to full DOF grid dataset.

**Setup**
- Input: 4 raw DOFs (hip 3 + knee 1), no velocity
- Model: V1 DistillNet with per-muscle decoders, 52M params
- Training: 9,475 epochs, pure MSE loss, final MSE = 7.16e-9

**Key findings**
- Constraint losses (fixed vertex, inter-muscle) are **wrong** for pelvis-local frame — fixed vertices move with their bones, penalizing displacement fights correct deformation
- Removing velocity from input eliminates frame-to-frame jitter (deterministic mapping)
- Per-motion checkpoint loading added to viewer (`volume_distill/{bvh_stem}_checkpoints/best.pt`)

## Walk L+R Mirror Training Pipeline

### Fixed issues
1. **`cap_attachments` not mirrored** in `tools/mirror_tet_L_to_R.py` — skeleton mesh indices (column 3) weren't offset by +12, so R muscle anchors attached to L bones during baking. Fixed and re-mirrored all 42 R tet files.

2. **`mirror_trained` flag dropped** in `volume_distill/dance/evaluate.py` `load_model()` — V1 metadata dict didn't pass through the flag, so viewer never enabled R-side inference.

3. **R displacement rest baseline mismatch** — R-mirrored rest positions differ from L rest (body not perfectly symmetric in pelvis-local). Training computed R displacements relative to R-mirrored rest, but inference added them to L rest → offset. Fixed by rebasing R displacements to L rest baseline in `walk_overfit_mirror.py`.

4. **Cache loader didn't search region subdirs** — `_motion_load_cache` only looked at top-level `data/motion_cache/{bvh}/` but baked files are in `L_UpLeg/`, `R_UpLeg/` subdirs. Added subdir search.

### Architecture
- Mirror training: R DOFs mirrored (negate hip X of rotation vector), R vertices mirrored (negate X in pelvis-local), all mapped to L-canonical names
- Inference: R DOFs [18-21] → negate hip X → predict in L-canonical → negate output X → apply to R_ muscles
- Exponential map (rotation vector) mirroring by negating X is equivalent to `diag(-1,1,1) @ R @ diag(-1,1,1)` — correct for sagittal plane mirror

## V2 PCA Mirror Training for Walk

Implemented V2 DistillNetV2-based mirror training script for walk data:

### New file: `volume_distill/walk_overfit_mirror_v2.py`
- Uses DistillNetV2 (shared encoder + single decoder with muscle embeddings)
- 20D derivative features: `[q_t, dq_t, ddq_t, q_{t-1}, q_{t-2}]` from 4 DOFs
- PCA output (K=64) with z-score normalization instead of per-muscle V×3 decoders
- Temporal consistency loss (frame pair training)
- L+R mirrored training (R DOFs: negate hip X; R displacements: each relative to own rest)

## V1PCA Implementation (Batched Decoders)

Implemented `DistillNetV1PCA` — V1 architecture with PCA output and all 25 decoders executed in parallel via `torch.bmm`.

**Key design:**
- Shared encoder (512 hidden, 3 ResBlocks) — same as V1
- 25 decoders stored as stacked 3D `nn.Parameter` tensors: `(M, in, out)`
- Single `torch.bmm` call per layer runs all muscles simultaneously
- PCA output (K=64) means all decoders have identical dimensions

**Stats:**
- 36M params (25 muscles), ~0.73ms/call on GPU (B=2)
- Compare: V1 was ~52M (V×3 output per muscle), V2 was smaller but shared decoder
