# Research Journal — 2026-04-28

## Iron-man bake collision tuning + analysis tools

### Tune iron-man bake collision (`e11693a`)
- `bake_layered.py`: use `bake_headless._update_tet_positions_from_skeleton` for warm-start (origin/insertion-bone blend) instead of bake_layered's own LBS.
- New flags: `--iron-man-offset` (default 5mm), `--inloop-collision` (taichi `collision_target_fn` callback), `--postcoll-rounds` (default 2), `--no-collision`.
- Per-iter convergence snapshot to `<cache>/_anim/frame*_layer*.npz` for offline iron-man playback.
- `viewer/skeleton_mesh.py`: `_compute_tet_skeleton_bindings` accepts `attach_skeleton_names` alone (contour tets only have names list populated).
- `viewer/bone_surface_collision.py`: post-ARAP vertex+edge bone collision helper as final pass in `solve_arap`.
- `viewer/muscle_mesh.py`: in-loop `_resolve_collisions_arap` opt-in (default off — ARAP undoes the push); final-pass uses new helper.

### New analysis/render tools
- `tools/render_iron_man.py`: offline pyrender renderer for per-iter cache dumps. Bone OBJs converted to body-local via rest-world transform.
- `tools/check_bone_penetration.py`: count post-bake muscle verts inside bone trimeshes at given frame.
- `bake_headless.py`: `--save-anim` hook + per-outer-iter snapshot callback.
