# Research Journal — 2026-04-24

## Anchor-bone assignment refinement for original-mesh tet

### Per-loop anatomical bone assignment (`09cef94`)
Each cap loop matched to one specific bone via XML waypoint endpoints (origin or insertion). Replaces all-caps-to-first-bone fallback.

### Bipartite origin/insertion assignment (`a747b0c`)
Multi-loop muscles (e.g., extensor with multiple insertions) need each loop assigned to a unique bone. Bipartite matching avoids conflicts where two loops both claim the same bone.

### Sub-contour per-end anatomical bone (`7bbf832`)
For loops near junctions, split contour into sub-pieces per anatomical end so partial assignments work.

### Per-waypoint bone lookup for multi-head muscles (`6539b35`)
Multi-head muscles (e.g., biceps brachii) have multiple origin waypoints belonging to different bones. Lookup now per-waypoint, not per-end.

### Anchor fan centroid to loop's dominant bone (`bafa750`)
Fan-cap centroid vert assigned to the loop's dominant bone (majority vote among loop verts), not nearest-bone.

### Nearest-bone-surface mesh-based classification (`5d9bc2e`)
Use trimesh nearest-surface query against bone OBJs for vert→bone, replacing BFS over skeleton hierarchy. More accurate near junctions.

### Skinning: use all anchors not just cap_attachments reps (`617d714`)
Cap attachment reps were only one vert per cap. Skinning weights now use all anchor verts, giving smoother bone-blend at attachment region.

### `anchor_bone_map` authoritative over `init_soft_body` BFS (`30f0457`)
When NPZ has anchor_bone_map (saved by tet_from_original_obj), `init_soft_body` uses it as ground truth and skips its own BFS. Was: BFS overrode the saved map.

### Prefer `contour_backup` as true contour source (`a763c98`)
For muscles with both original and contour tet, use contour_backup (saved contour mesh state) as the canonical contour source. Original tet may have been re-derived and lost original waypoint info.

### Tet + skinning: no orphans, no zero-weight, no stuck verts (`d390d62`)
Final defense pass: no orphan verts (incident tet check), no zero-weight skinning (all verts get ≥ one nonzero bone weight), no stuck verts (verts at exact bone-attachment positions get unstuck via small offset toward muscle interior).
