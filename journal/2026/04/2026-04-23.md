# Research Journal — 2026-04-23

## Original-mesh tet pipeline matches contour pipeline

### XML-waypoint anchor fallback for closed OBJs (`0e43394`)
Closed-boundary OBJs (no open loops) had no anchors detected. Added fallback that uses XML waypoint endpoints as anchors when no boundary loops exist.

### Hi-res `Zygote_Meshes_251229` OBJs with subprocess tetgen (`49689d6`)
Switched from low-res mesh to hi-res Zygote_Meshes_251229 OBJs. Subprocess tetgen wraps to avoid in-process segfault on dirty input.

### Watertight: close every boundary loop (`416bbfa`)
For each open boundary in OBJ, fan-cap with centroid to make watertight before tetgen. Mirrors contour mesh approach.

### Per-cap bone assignment like contour mesh (`db583cd`)
Each cap loop assigned to a specific bone (origin/insertion side) using nearest-bone heuristic. Was: all cap verts default to first bone.

### Save `anchor_bone_map` for per-vert override (`54cc13e`)
NPZ output now includes per-vert bone assignment override map. Viewer `init_soft_body` reads this instead of doing BFS-based assignment.

### `strip_fold_faces`: protect cap faces (`1fdc48d`)
Tool that strips render faces folding under ARAP. Now protects cap faces (origin/insertion) from being stripped. Default threshold raised 0.5 → 0.7 (was over-aggressive).
