## Viewer-hook BVH→zygote retarget (.npy override)

Final solution after weeks of conversion-error debugging on
LaFAN walk1_subject1.bvh: bypass MyBVH chain-conjugation entirely
by writing mocap_refs as `.npy` next to `.bvh`, viewer loads `.npy`
directly.

**Bake (`tools/bake_zygote_mocap.py`):** per-frame DART FK computes
target skel pose. Humerus orientation set via TWO-vector basis:
- bone direction X_local_hum → d_bvh_hum (shoulder→elbow vector)
- ulna flex axis Z_local_hum → unit(d_bvh_hum × d_bvh_fore)

This pins humerus twist so the elbow flex plane contains BVH forearm.
Ulna revolute angle then resolves to align d_chain_fore with d_bvh_fore
exactly.

DART Ball body world formula (verified empirically):
```
body_world = par_world @ T_p2j @ expmap(rv) @ T_c2j.T
expmap(rv) = T_p2j.T @ par_after.T @ body_world_target @ T_c2j
```
T_p2j/T_c2j are XML rest transforms FromParent/FromChild on the joint.

**Scapulohumeral 0.27 share:** R_delta = hum_target @ hum_init.T,
clavicle absorbs `share * rotvec(R_delta)` (conjugated through clavicle
joint world frame), humerus absorbs remainder.

**Viewer (`viewer/zygote_mesh_ui.py`):** after `MyBVH(...)`, checks for
sibling `.npy` and overrides `motion_bvh.mocap_refs` if shape matches.

**Verify (`tools/verify_npy_mocap.py`):** loads npy, sets skel
positions, compares shoulder→elbow and elbow→wrist directions against
BVH FK targets.

Walk1_subject1 result:
- L/R Humerus cosθ ≥ 0.9999 across all sampled frames.
- L/R Forearm cosθ ≥ 0.9951 across all sampled frames.
