# Research Journal — 2026-05-06

## Level selection: spacing-based search + caching

Switched the auto level-selection criterion from min consecutive
gap to mean of consecutive gaps so a single tight pair no longer
forces rollback to `min_count`.  Default min-spacing threshold
lowered to 4cm (0.04m); slider `Min Spacing (m)` shared globally
across all muscle trees.

Spacing search loop now also logs every consecutive pair's gap
plus the per-stream mean for both the auto-find iterations and the
GUI Reselect button.

## DP performance: per-session caches

Independent multi-stream muscles (biceps femoris) ran much slower
than single-stream because each iteration of the spacing search
rebuilt:

- per-(stream, level) inertia tensors inside `_level_error_stream`
- the O(n^3) `cost_mat` for every new target K

Both depend only on the unchanging stream contour set, so cached
on `self` for the lifetime of the `select_levels` session:

- `_level_select_inertia_cache[s][li]`
- `_level_select_cost_cache[key]` keyed by `('stream', s)` /
  `('global',)` so K=3, K=4, ... reuse the same matrix
- `_level_select_dp_cache[key]` so a rollback to a previously-tried
  target hits cache instead of rerunning DP

## Cut-muscle linkage robustness

Two issues fixed:

- `select_levels` rebuilt `stream_groups` as fully-independent on
  any length mismatch, collapsing cut muscles into per-stream DP.
  Replaced with pad-with-last-entry / truncate so existing linkage
  survives.
- Initial UI checkbox propagation only fired at levels with a
  multi-stream group.  Made cut-muscle propagation global, then
  reverted: split levels of a cut muscle should toggle
  independently.  Final behavior: per-level `is_this_linked` only.

## UI: globally-synced controls

Replicated the Min Spacing pattern for two more controls:

- `Animate` checkbox → `v.global_animate_process`
- Vertical Process step slider → `v.global_process_step`

Toggle/move on any muscle propagates to every other muscle's tree.

## Misc

- `select_levels` now logs per-stream spacings on every selection.
- Removed orphaned `for-else` clause that survived the per-stream
  refactor and tripped a `SyntaxError`.
- Single-stream `select_levels` no longer crashes when
  `stream_groups` length lags `num_levels`.
