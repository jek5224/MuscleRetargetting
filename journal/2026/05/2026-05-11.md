# Research Journal — 2026-05-11

## Bake tremble root cause + minimum iter sweep

### Problem
Persistent per-frame tremble on Gastrocnemius, Tensor_Fascia_Lata, Soleus etc. in baked motion cache for `walk.bvh`. Previous sessions had tried: muscle-aware ARAP off/on, skin prior off/on, inter-muscle constraints off/on, self-collision off, EMA on axis_ratio removed — none eliminated tremble.

### Diagnosis
The ARAP solver's **plateau early-exit** (2% max_disp drop over 30-iter window) was the cause. Different frames exited at different iter counts (distribution: 26 frames @ 30 iters, 100 @ 60, 6 @ 90; none reached `tolerance=1e-4`). Frames terminated at varying residuals → frame-to-frame jitter = tremble.

### Fix
- Added `--no-plateau-exit` flag to `tools/bake_headless.py` → propagates to `viewer/arap_backends.py:solve()` via `disable_plateau_exit=True`.
- With this flag, every frame runs full `--settle-iters`. Uniform convergence depth → no tick.

### Minimum iter sweep (per-region bake on a6000)
Snapshotted full 37-muscle bake at `--settle-iters 150 --no-plateau-exit` as ground truth. Swept `[100, 75, 50, 30]` on a [95,110] window.

Peak motion frame 106, max-vert delta vs iter150:
| iters | worst Δ | speedup |
|-------|---------|---------|
| 100 | 0.64mm | 1.36× |
| 75 | 2.31mm | 1.56× |
| 50 | 7.31mm | 2.18× |
| 30 | 18.7mm | 2.91× |

Numerical cliff between 75 and 50.

### Per-region bake (split `.last_loaded_muscles.json`)
Splitting the 37-muscle JSON into `.muscles_LowLeg.json` (12) + `.muscles_UpLeg.json` (25) drops cross-region inter-muscle constraints but lets the unified ARAP system shrink → faster per frame. Server bake times:
- L_LowLeg @100: 1.68s/frame (255s total, 132 frames)
- L_UpLeg @100: 1.05s/frame (147s total)
- L_LowLeg @50: ~1.0s/frame (130s)
- L_UpLeg @50: ~0.55s/frame (75s)

### Visual verdict
At @50 per-region, no visible ticking in viewer for either region — despite numerical 5-7mm delta on Soleus/Gastrocnemius vs @100. The numerical delta means @50 settles to a different equilibrium, but as long as that equilibrium is internally frame-consistent, no tremble.

**Conclusion: `--settle-iters 50 --no-plateau-exit` per-region is the new bake baseline.**

### Tools added
- `tools/diff_caches.py` — per-muscle max/RMS/p95 L2 vertex delta between two cache dirs.
- `tools/find_peak_frame.py` — identifies frame with maximum per-vert displacement from prior frame.
- `tools/slurm_walk_iter.sh` — parameterized server bake submitter: `sbatch slurm_walk_iter.sh <REGION> <ITERS>`.

### Open follow-up
- Early-exit could be re-enabled with absolute residual gate (`max_disp < 1e-3m`) instead of relative-plateau: uniform exit residual, fast-pose frames exit early. Not implemented; only useful for long varied BVHs with static stretches. walk.bvh has motion throughout so no static frames to save.
- Rsync needs `--delete` when re-syncing cache dirs from server — otherwise stale chunks from prior bake leak into the new cache. Caused a confusing diff result mid-session.
