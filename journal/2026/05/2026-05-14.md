## Walk v1dec training (4-region, 7-DOF, mirror)

Submitted multiple training variants in parallel on a6000 server.

- **v1** (40480): LR=3e-4 ReduceLROnPlateau, HIDDEN_DIM=768, 3+2 res. Baseline.
- **v2** (40481): LR=1e-3 cosine + 50-step warmup. Final val_loss **2.66e-7**.
- **v3** (40484): v2 + temporal smoothness λ=0.5. Final **1.57e-7** (41 %
  lower than v2). Confirmed temporal regularization helps walk's tight
  pose distribution.
- **v4** (40485): v3 + acceleration term + HIDDEN_DIM=1024, 4+4 res blocks.
  Final **9.95e-8**. Best yet, ~17 hours total.

Reference: dance v1dec was 1.36e-7 at epoch 8258. Walk now beats dance.

Mid-training crash on initial run because of file overwrite race on
`best_v1dec.pt` (3.3 GB save every new best). Fixed: rate-limit save to
every 100 epochs + drop optimizer state (saved 4 × wall clock).

## Reverse-LBS analysis: moment-arm fiber clustering

Built `tools/fiber_moment_arm_analyze.py` to identify functional sub-groups
within each muscle. Per-pose moment arm via local LS regression
`L_i ≈ m_i · q + b_i` with sliding window, ridge regularization, boundary
mask. K=8 hierarchical clustering on per-fiber moment-arm trajectories.

Visualization per muscle: dendrogram + per-cluster mean MA on dominant DOF
+ all-DOF mean across fibers + 3D rest fiber paths colored by cluster
(three views with Y up). Saved 37 R muscle plots to `analysis_images/`.

Key findings (sign-flip across fibers = multi-compartment muscle):
- **Gluteus_Maximus**: sign-flip on hip_z. Multi-compartment sheet.
- **Gluteus_Minimus**: sign-flip on hip_y. Anterior/posterior split.
- **Adductor_Magnus**: sign-flip on hip_x. Anterior flexor + posterior
  extensor (textbook).
- **Tensor_Fascia_Lata**: sign-flip on hip_x. Unusual.
- **Popliteus**: sign-flip on knee — suspicious. Likely DOF collinearity
  artifact in walk poses (knee+ankle correlated during swing).

Reference: Blemker & Delp 2005 (3D FEM muscle moment-arm variation) +
Delp tendon-excursion method.

## R muscle waypoint bugs

### Bug 1: Toe insertion body name digit doubling

`tools/mirror_tet_L_to_R.py:_mirror_body_name` converted `L_Toe50` →
`R_Toe550` (doubled middle digit). 4 R LowLeg muscles affected
(Extensor_Digitorum_Longus, Extensor_Hallucis_Longus, Flexor_Digitorum_Longus,
Flexor_Hallucis), 1000 broken entries. Fixed `_mirror_body_name` to use
digit-suffix-aware strip; patched existing tet files via
`tools/fix_r_toe_body_names.py`.

### Bug 2: Skeleton-attached `local_pos` inversion

Mirror script's `local_pos[0] *= -1` was wrong for limb bones whose rest
rotation matrices are NOT mirror-symmetric (L_Femur vs R_Femur differ in
more than just X sign). All 37 R muscles had wrong origin/insertion local
positions. Worst case: R Gluteus Medius insertion world was at Y=0.57
(below femur head) instead of Y=0.93 (greater trochanter), 36 cm error.

Fixed via `tools/fix_r_skeleton_waypoints.py`: per L skeleton-bound
waypoint, compute world via L body, mirror X, inverse-transform through
R body to derive R local. 10000 entries corrected across all R tet files.

Cache regenerated via `tools/regen_waypoints.py` (R_UpLeg + R_LowLeg).
Verified: R origin/insertion now at correct world positions (matches L
mirrored).

## Viewer fiber rendering segfault fixes

Multiple stale-VBO crashes during NN reload + cache reload. Root cause:
glColorPointer's array reference held by GL driver across frames, freed
by Python GC. Mitigations applied:
- Both depth-fade and fast paths switched to client-side numpy arrays
  with explicit float32+ascontiguous + kept-alive on `self`.
- Explicit `glBindBuffer(GL_ARRAY_BUFFER, 0)` before client array draw
  to clear any stale VBO binding.
- `glDisableClientState(GL_COLOR_ARRAY)` cleanup between paths.
