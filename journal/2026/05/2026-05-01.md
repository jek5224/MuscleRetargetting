# Research Journal — 2026-05-01

## Tetrahedralization improvements for ARAP

Reworked tet pipeline to feed cleaner meshes to ARAP. Targeted L_Soleus + L_Extensor_Digitorum_Longus on lower-leg group.

### Changes

**`viewer/contour_mesh.py`**
- Skip degenerate quads in zipper band (cross-stream merge collapses 4 corners onto <3 unique verts)
- Skip degenerate triangles in `_emit` helper

**`viewer/contour_animation.py`**
- State save/restore now persists `_face_stream_map` + `_shared_vertex_pairs`. Without these, replay/restore wiped them and tet subprocess collapsed to single-component path → catastrophic NM-edge failure on multi-stream muscles.

**`viewer/tetrahedron_mesh.py`**
- T-junction loop guard in `_cap_faces`: if loop has duplicate verts, skip CDT (Triangle C library segfaults on figure-8), use centroid fan
- Pre-TetGen vertex weld (defensive, eps=4 decimals scaled mm)
- Pymeshfix collapse defense: reject result if <10% verts preserved (avoids 937v→3v stub that crashed subprocess)
- Drop sliver + still-inverted tets post-orientation-flip (sliver_eps adapts to mesh volume)
- ARAP validation: count orphan/weak anchors, log summary
- Anchor summary print replaces ~200 lines of per-anchor pole/face checks
- `_face_stream_map` length mismatch recovery + clear diagnostic

### Results

**Soleus** (2-stream cut muscle):
- Per-stream watertight=True for both comps (was nm=18,8)

- All 124 anchors connected ≥3 incident tets, max_d=0

- ARAP-fit

**Extensor** (5-stream heavily-cut muscle):
- All 5 components STRICT TetGen ok (was Delaunay+inside fallback or full failure)
- 0 orphan anchors (was 23 orphan), 0 inverted

- max_d=50mm — 99/200 anchors >1mm displaced. Limit: pymeshfix still discards 30-83% of per-stream surface verts due to NM edges from contour mesh build.

### Open: parametric offset finder

Tried param-based rotation offset for zipper bands (replacing 3D vertex-distance minimizer). Param finder picks offset=0 consistently, giving topologically clean alignment. But it exposed pre-existing contour-mesh holes (1-13mm gaps at stream junctions where cross-stream merge eps=1mm missed pairs). Bad-offset behavior was masking holes with overlapping garbage triangles. With correct offsets the holes are visible → cap CDT creates self-intersecting fills → pymeshfix collapses comp 2 to stub → segfault.

Reverted to 3D distance offset finder. Real fix needs upstream rework in `build_contour_mesh`:
- Param-based cross-stream merge (not just position-based with 1mm eps)
- Explicit hole-fill at stream junctions
- Param-aware offset finder that doesn't break when verts haven't merged

Estimated ~200 lines, separate workstream.

### Verdict

Soleus near-perfect. Extensor ARAP-functional with degraded anchor positioning (geometric error, not topological). Suitable to bake; bone binding visibly off at ~half anchors on heavily-cut Extensor.
