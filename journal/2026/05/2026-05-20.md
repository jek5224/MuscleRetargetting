# Research Journal — 2026-05-20

## Reverse-LBS feasibility study

Solved per-waypoint 2/3-bone LBS from `walk.bvh` cache for all 74 R/L muscles.
Residuals (95th percentile vs. baked cache):
- Monoarticular (vastus, glutes, adductors): **<5 mm**
- Biarticular (sartorius, gracilis, hamstrings, RF, gastrocnemius): **5–12 mm** with 3-bone path
- All 10000 fibers fit within 15 mm max residual

Per-waypoint records saved to `reverse_lbs_results/{muscle}.npz`:
`(stream, level, fiber, origin_body, mid_body, insertion_body,
local_o, local_m, local_i, w_o, w_m, w_i)`.

Bone-selection rule: kinematic chain LCA between origin/insertion. Chain ≥2
intermediates → biarticular → 3-bone with middle bone closest to fiber
midpoint. Otherwise 2-bone.

## P1: env.py arc-length weight inversion fix

`loading_zygote_muscle_info` had `weights = [l_origin, l_insertion]/total`,
meaning weight on origin bone was SMALL near origin → muscle belly tracked
insertion bone instead of origin. Swapped to `[l_insertion, l_origin]/total`
so closer bone gets higher weight (standard LBS convention).

Only affects intermediate waypoints — endpoints already go through DART's
single-bone branch.

## 3-bone LBS extension (no C++ rebuild needed for this part)

Extended `loading_zygote_muscle_info` to detect biarticular muscles via
kinematic chain. For chain length ≥2, passes
`bn_names=[origin, mid, insertion]` + per-waypoint tent weights
`(w_o, w_m, w_i)` to `addMuscleWeight`. C++ already supports K bones; only
Python side needed the extension.

## dartpy binding: `addMuscleAnchorExplicit`

Added new `Muscle::AddAnchor(bnodes, locals, weights)` overload + binding
to feed solver-tuned **per-bone local positions** directly (bypasses DART's
inverse-derivation from a single world position). Required for full solver
fidelity off-rest pose — single `glob_pos` API can't encode K independent
locals.

Changes:
- `dart/python/dartpy/dynamics/Muscle.h`: new overload decl +
  `addMuscleAnchorExplicit` method.
- `dart/python/dartpy/dynamics/Muscle.cpp`: overload impl + Python binding.
- Rebuilt dartpy, installed to pyMAC venv. Backup `.so.bak` kept.

Verified: `dart.dynamics.Muscles.addMuscleAnchorExplicit` callable from
Python.

## Muscle XML pipeline

- `data/zygote_muscle_revised.xml`: f0 values pulled from `muscle284.xml`.
  Biceps_Femoris split into `_Long` (f0=705.2) + `_Short` (f0=157.9).
  Gastrocnemius split into `_Medial` (f0=1308) + `_Lateral` (f0=606.4).
  Iliacus uses Psoas_Major's f0 (239.85). 78 Units total.
- LBS attributes injected into every `<Waypoint>` of `_revised.xml`:
  `lbs_bones`, `lbs_locals` (semicolon-separated per-bone locals),
  `lbs_weights`. Backward-compatible — legacy parsers ignore unknown attrs.
- `data/zygote_muscle_reverse.xml`: solver-reconstructed world rest + best
  body per waypoint. K-bone info not in this schema (lossy).
- `data/zygote_muscle_100.xml`: flattened version (one Unit per fiber, no
  `<Fiber>` tags). 10000 Units.
