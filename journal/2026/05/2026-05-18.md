# Research Journal — 2026-05-18

## Reverse-LBS viewer integration polish

Hooked reverse-LBS toggle into all frame-change paths so waypoints stay
synced with current skel pose:
- BVH frame slider (manual scrub)
- Step -1 / Step +1 buttons
- Auto-play (`_motion_step_forward`)
- R reset / Z zero reset (`reset` / `zero_reset` in zygote_mesh_ui.py)

Reset path additionally forces `_fiber_draw_dirty = True` per muscle so
rebuild fires on the next draw — without this, the fast VBO cache held
old frame's waypoint positions across the pose change.

## Fiber draw path consolidation

Both the depth-fade and the fast-VBO paths in `draw_fiber_architecture`
switched to client-side numpy arrays (kept-alive on `self._fiber_*_
keepalive`). Eliminates intermittent segfaults at `glDrawArrays` when
waypoint structure changes between frames (NN reload, reverse-LBS toggle,
muscle add/remove). Trade-off: minor per-frame upload cost, far outweighed
by stability.

## Walk BVH load speedup

`_motion_load_cache` was iterating all 74 muscle names regardless of tet
state, scanning external-drive cache dirs per muscle. For walk1_subject1
(7840 frames × 25 muscles = 35k chunks) this took **419 s**. Skipping
muscles whose `tet_vertices is None` cuts cold-load to a few seconds
when no tets are loaded. Cache still loads automatically once any
muscle's tet is loaded.

## Reverse-LBS toggle parity with frame events

Confirmed solver-driven waypoints visually match baked cache during
playback for the muscles passing the <5 mm residual threshold. Larger
residuals visible as faint jitter on long biarticular muscles (sartorius,
gracilis) at extreme swing phase — acceptable.
